页面计数

Kestrel

页面请求到达边缘、并且主机名在站点白名单里时，累计四个整数。页面上的脚本只把这四个数填回来。

脚本只读 · 四个整数

站点访问

—

site_pv

本页访问

—

page_pv

站点访客

—

site_uv

本页访客

—

page_uv

本页自己的脚本使用站点 %%SITE_ID%%（构建时取 sites.json 里第一个写了主机名的站点）和相对地址 /v1/track。直接打开 127.0.0.1 时，只有把该主机名写进白名单才会给这一次打开加一。

HTML

嵌入代码

<script
  defer
  src="https://your-domain.example/kestrel.js?v=%%VERSION%%"
  data-site="%%SITE_ID%%"
  data-endpoint="https://your-domain.example/v1/track"
></script>
<span id="kestrel_container_site_pv" style="display:none">本站访问 <span id="kestrel_value_site_pv"></span></span>
<span id="kestrel_container_page_pv" style="display:none">本页访问 <span id="kestrel_value_page_pv"></span></span>
<span id="kestrel_container_site_uv" style="display:none">本站访客 <span id="kestrel_value_site_uv"></span></span>
<span id="kestrel_container_page_uv" style="display:none">本页访客 <span id="kestrel_value_page_uv"></span></span>

步骤

使用说明

  1. 1
    把上面的脚本和四个元素放进要显示数字的 HTML。data-site 填 sites.json 里的站点 id。脚本请求 GET /v1/track，把站点访问、本页访问、站点访客、本页访客写入 kestrel_value_*，再把 kestrel_container_* 显示出来。这次读取不会加一。
  2. 2
    数字增加发生在 HTML 文档请求到达本边缘时。HTTP Host 必须和该站点在 sites.json 里的某个主机名一致。静态资源、kestrel.js 和 /v1 接口不计。
  3. 3
    页面如果没有经过这个边缘，访问量不会增加。脚本仍然可以读出已经记下的四个数。
  4. 4
    POST /v1/track 返回 405，不会增加 PV 或 UV。
